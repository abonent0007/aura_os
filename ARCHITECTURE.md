# AURA v4.1.0 — Схема работы

## Ядро
- **Agent**: ReAct × 30 циклов, умная фильтрация инструментов по триггерам
- **Окно истории**: 6 сообщений (3 обмена) + авто-сжатие
- **Инструменты**: 32 ядра + 140+ скиллов с кешем определений
- **Создание скиллов**: изолированный контейнер без истории диалога

## Контекст (на каждый запрос)
| Приоритет | Что | Размер |
|-----------|-----|--------|
| 1 | SYSTEM_PROMPT (кешируется DeepSeek) | ~5.5K |
| 2 | Сжатая история + факты | ~300 |
| 3 | Последние 6 сообщений | ~2K |
| 4 | Сообщение пользователя | ~100 |

## Инструменты (отправляются по триггерам)
- **Всегда**: память, календарь, погода, веб-поиск, браузер, диагностика
- **По триггерам**: 140+ инструментов скиллов (загружаются только при совпадении слов)
- **Приветствия**: без инструментов

## Голос (TTS)
1. `_normalize_for_tts`: цифры → слова, значки → текст
2. `_clean_for_tts`: удаление markdown и кода
3. Silero TTS v5: чанки по 150 символов + паузы
4. Потоковая озвучка: первые 2 предложения мгновенно, остальное параллельно

## База данных
- `aura.db`: память, календарь, факты, трассировка
- `aura_soul.db`: дневник, сны, эмоции, ритуалы, контекст
- Миграции через `schema_version`
