# Browser Automation

Headless-браузер на базе Playwright. Позволяет Ауре просматривать страницы, делать скриншоты, собирать данные и заполнять формы — как человек, но автоматически.

## Возможности
- Скриншоты страниц (полностраничные или viewport)
- Извлечение текста с динамических страниц (JavaScript-рендеринг)
- Заполнение форм и клики
- Сбор структурированных данных по CSS-селекторам
- Проверка статуса браузера и Playwright

## Инструменты
- `browser_screenshot` — скриншот страницы (сохраняется в папку скилла)
- `browser_get_text` — извлечь текст со страницы (весь или по селектору)
- `browser_fill_form` — заполнить поле ввода на странице
- `browser_click` — кликнуть по элементу
- `browser_extract_data` — собрать структурированные данные (заголовки, цены, ссылки)
- `browser_status` — проверка что Playwright и браузер готовы к работе

## Требования
- **Playwright**: `pip install playwright`
- **Chromium**: `playwright install chromium`
- Браузер запускается в headless-режиме, невидимом для пользователя

## Ограничения
- Максимум 3 страницы за один вызов (защита от перегрузки)
- Таймаут 20 секунд на страницу
- Скриншоты сохраняются в `skills/browser-automation/screenshots/`

## Безопасность
- Не сохраняет cookies между сессиями
- Не передаёт пользовательские данные сайтам без явной команды
- Все скриншоты локальны, не отправляются вовне

## Примеры использования
- «Сделай скриншот страницы https://example.com»
- «Собери все заголовки новостей с главной lenta.ru»
- «Заполни форму на сайте и сделай скриншот результата»
- «Найди цены на товар по ссылке и выведи списком»
