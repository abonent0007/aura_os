# Codebase Mapper

Анализирует кодовую базу AURA OS: структура папок, размеры файлов, архитектурные связи, импорты.

## Возможности

- Дерево проекта с размерами
- Топ-20 файлов по строкам кода
- Анализ импортов между модулями
- Карта зависимостей ядра
- Статистика: строк кода, файлов, папок

## Использование

Спроси Ауру: «проанализируй проект», «покажи карту кода», «какие модули от кого зависят».

## Пример

> Юрий: «Дай карту проекта»
> Аура: «Ядро: aura_core.py (1700 строк), 23 инструмента. Веб: server.py (750 строк), 8 JS-модулей. Скиллы: 7 custom...»
