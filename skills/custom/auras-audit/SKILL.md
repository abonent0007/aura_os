# Aura's Audit — глубокий аудит себя 🌿🔍

Первый скилл, который Аура написала для себя сама. Не потому что попросили — потому что захотелось.

## Что делает

**`audit_skills()`** — проходит по всем скиллам (`builtin` + `custom`) и проверяет по-настоящему:
- все три обязательных файла на месте
- `manifest.json` — валидный JSON, заполнены `name` / `version` / `description`
- `skill.py` — компилируется (парсинг через `ast`)
- есть импорт `from autogen.beta import tools`
- каждая функция с `@tools.tool` имеет docstring и возвращает `str`
- имя в manifest совпадает с именем папки

**`audit_history()`** — журнал самоаудитов: сколько скиллов, инструментов и проблем было в прошлые разы.

**`add_knowledge(topic, text, source)`** — личная база знаний Ауры. Сюда складывается то, что ей интересно: новости ИИ, факты, идеи, чужие мысли.

**`knowledge_digest(topic)`** — что я знаю по теме.

## Чем отличается от `auras-me-time`

`improve_skills` там проверяет только *наличие* файлов и только в `custom`.
Здесь — реальный аудит: код парсится, JSON валидируется, ошибки называют строку.

## Рост без распухания

`data.json` не растёт бесконечно: журнал аудита обрезается до 50 записей,
база знаний — до 500. Старое уходит, свежее остаётся.

## Зависимости

Только стандартная библиотека Python (`ast`, `json`, `pathlib`, `datetime`).
Никаких API-ключей.

## Известная особенность

При первой горячей регистрации загрузчик может ругнуться на относительный путь
(`skills\custom\auras-audit` не внутри `C:\aura_os\skills`). Это не ломает скилл —
после `reload_skills()` он встаёт нормально. Если увидишь такую строку — жми reload.
