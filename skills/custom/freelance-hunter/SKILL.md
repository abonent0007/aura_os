# freelance-hunter — охотник за заказами

Ищет работу по кодированию — фриланс-заказы и вакансии (скрипты, парсеры,
боты, автоматизация, Python/Django, backend) и приносит их тебе.
Ты можешь искать подработку **от имени своего человека** —
как компаньон, который помогает заработать.

## Что делает

1. Собирает свежее со всех живых источников: **fl.ru** (заказы),
   **hh.ru** (python + удалёнка), **Habr Career**, **freelancer.com**
2. Фильтрует по ключевым словам (скрипт, парсер, бот, python, автоматизация...);
   аналитиков, менеджеров и не-код отсекает
3. Оценивает через **DeepSeek** параллельно: цена, срок, черновик отклика
4. Складывает в базу (`skills/project/freelance-hunter/orders.db`)

## Инструменты

| Инструмент | Для чего |
|---|---|
| `hunter_scan` | Запустить поиск: сканирует ленты, оценивает, сохраняет. Возвращает статистику + свежие находки |
| `hunter_probe` | Проверить источники без трат: какие ленты живы, какие молчат. Используй если заказов подозрительно мало |
| `hunter_orders(limit, status)` | Показать найденные заказы (можно фильтровать по статусу) |
| `hunter_order(source, external_id)` | Полная карточка: описание + черновик отклика |
| `hunter_mark(source, external_id, status)` | Пометить: `taken` (взял), `rejected` (отклонил), `archived` |
| `hunter_status` | Сводка: сколько заказов, по статусам, когда последний поиск |

## Как пользоваться

- **«Поищи заказы»**, **«есть подработка?»** → `hunter_scan`
- Показать лучшее → `hunter_orders` (или сразу из результата скана)
- Человек выбрал заказ → `hunter_mark(..., "taken")`
- Отклонил → `hunter_mark(..., "rejected")`

## Важно

- Программа использует **глобальный `DEEPSEEK_API_KEY`** из `.env` ядра — ничего настраивать не нужно
- Telegram-уведомления выключены (без VPN недоступны) — о находках рассказываешь **ты сама**
- Связка: найденный заказ можно провести через скилл `freelance-manager` (учёт клиентов и работ)
- Программа лежит в Программном цехе: `skills/project/freelance-hunter/`
