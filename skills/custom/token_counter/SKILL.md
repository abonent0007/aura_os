# Счётчик токенов

Подсчитывает обращения к DeepSeek API, потраченные токены и их стоимость в рублях.

## Возможности
- Логирование каждого обращения: prompt_tokens, completion_tokens, модель
- Подсчёт стоимости по тарифам DeepSeek (в рублях)
- Статистика за период: сегодня, неделя, месяц, всё время
- Отображение «аппетита» Ауры — сколько она «съела» токенов

## Инструменты
- `log_usage` — записать использование токенов после ответа
- `get_token_stats` — показать статистику за период
- `get_appetite` — краткая сводка аппетита

## Зависимости
- нет

## Примеры использования
- "Сколько токенов мы потратили за сегодня?"
- "Какой у тебя аппетит?"
- "Покажи общую сумму за неделю"
- "Сколько рублей мы сожгли на запросах?"

## Примечания
- Тарифы захардкожены под DeepSeek, курс доллара ~100₽
- Данные хранятся в data.json внутри папки скилла
