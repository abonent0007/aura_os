# Test Runner

Запуск тестов скиллов AURA OS.

## Возможности
- Автоматический прогон тестов для всех скиллов
- Проверка синтаксиса skill.py
- Валидация manifest.json

## Инструменты
- `run_tests` — запуск всех тестов

## Зависимости
- нет

## Примеры
- "Запусти тесты скиллов"
- "Проверь все скиллы на ошибки"
