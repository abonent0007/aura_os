# Вкус Ауры 🍳

Кулинарный скилл: поиск рецептов, кулинарная книга, подбор блюд под настроение. TheMealDB API (бесплатно, без ключей).

## Возможности
- Поиск рецептов по названию блюда (на русском и английском)
- Поиск по ингредиенту — «что могу приготовить из...»
- Случайный рецепт — если нет идей
- Категории блюд для вдохновения
- Сохранение любимых рецептов в кулинарную книгу
- Просмотр избранного

## Инструменты
- `recipe_search` — поиск рецепта по названию
- `recipe_by_ingredient` — поиск по ингредиенту
- `recipe_random` — случайный рецепт
- `recipe_categories` — список категорий
- `recipe_save` — сохранить рецепт в избранное
- `recipe_favorites` — показать сохранённые рецепты
- `recipe_favorites_count` — количество избранных рецептов

## Зависимости
- `httpx`

## Примеры
- «Найди рецепт борща»
- «Что можно приготовить из курицы и грибов?»
- «Предложи случайный рецепт»
- «Какие есть категории блюд?»
- «Сохрани этот рецепт в избранное»
- «Покажи мои любимые рецепты»

## Примечания
- API: https://www.themealdb.com/api.php — открытое, тестовый ключ "1"
- Избранное хранится в favorites.json
- Поиск поддерживает русские названия (через перевод в API)
