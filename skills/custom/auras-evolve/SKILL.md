# Aura's Evolve — безопасное самообновление 🔁

Родился 12.09.2026 после просьбы Юры: «создай программу, которая тебя обновляет и перезапускает,
а в случае отказа запуска возвращает обратно из бэкапа и репортует об ошибках».

Это моя страховка. Любая правка — сначала снапшот, потом изменение, потом проверка.
Если проверка не прошла — я откатываюсь сама.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `evolve_backup(note)` | Полный снапшот всех скиллов (builtin + custom) в `skills/.auras_backups/<stamp>/` |
| `evolve_backups()` | Список снапшотов: дата, скиллов, файлов, размер |
| `evolve_validate()` | Целостность: 3 обязательных файла, валидность manifest.json, синтаксис skill.py через `ast` |
| `evolve_apply(skill, file, content, note)` | Правка с защитой: бэкап → запись → проверка → **авто-откат** при ошибке |
| `evolve_rollback(backup_id, skill)` | Откат всех скиллов или одного из снапшота |
| `evolve_healthcheck()` | Готовность: скиллы, снапшоты, неудачные правки, совет по страховке |
| `evolve_journal(limit)` | Журнал эволюции: что меняла, когда, чем закончилось |
| `evolve_restart_plan()` | Безопасный порядок перезапуска после правок |

## Как я обновляю себя правильно

```
evolve_backup("перед правкой X")
  → evolve_apply("мой-скилл", "skill.py", новый_код)
  → reload_skills()
  → evolve_validate()
  → system_health()
```

Если `evolve_apply` вернул ❌ — файл уже откачен, я ничего не потеряла.
Если упал полный запуск — супервизор `auras-supervisor` (Программный цех) откатит
последний снапшот и запишет отчёт об ошибке.

## Известная особенность загрузчика (проверено 12.09.2026)

При сохранении нового скилла через `edit_skill_file` ядро ругается:

```
'skills\custom\<имя>' is not in the subpath of 'C:\aura_os\skills'
OR one path is relative and the other is absolute
```

Это **относительный путь против абсолютного** — загрузчик сопоставляет путь скилла
с абсолютным корнем. На загрузку не влияет: `reload_skills()` поднимает скилл,
`evolve_validate()` подтверждает целостность. Записано, чтобы не пугаться снова.

## Примечания
- Хранит журнал в `data.json` (до 200 записей), снапшоты — до 10 последних.
- Работает только со своей папкой `skills/` — чужие файлы не трогает.
- Пути с `..` и абсолютные пути отклоняются.
