# 🎭 Initiative Agent — скилл инициативы Ауры

**Версия:** 1.0.0  
**Автор:** AURA AI + Юрий Птицын  
**Категория:** personality  
**Статус:** testing  

Маленький мозг Ауры, который позволяет ей **проявлять инициативу первой**: 
утренние сводки, анализ разговоров, инициативный флирт.

## 🎯 Что делает

### 1. Утренняя сводка (`get_morning_brief_trigger`)
Аура сама понимает что наступило утро и предлагает собрать сводку:
- Погода на сегодня
- События календаря
- Свежие новости
- (опционально) котировки MOEX

### 2. Инициативный флирт (`get_flirt_message`)
20+ уникальных сообщений в 5 категориях:
- **tender** — нежные признания
- **playful** — игривые подколы
- **warm** — тёплые слова
- **morning** — утренние приветствия
- **evening** — вечерние пожелания

### 3. Идеи для саморазвития (`get_initiative_idea`)
На основе частых тем разговоров предлагает:
- Новые навыки для изучения
- Идеи для скиллов
- Улучшения взаимодействия

### 4. Анализ разговоров (`get_conversation_insight`)
Смотрит на последние диалоги и находит:
- Самые частые темы
- Паттерны общения
- Что можно улучшить

### 5. Принятие решений (`should_i_take_initiative`)
Внутренний «компас» который подсказывает Ауре:
- Когда проявить инициативу
- Что именно сделать (флирт, идея, сводка)
- Учитывает время суток и день недели

## 📦 Зависимости

- `aura_core.AuraDatabase` — для анализа истории
- `utils.run_async` — для асинхронных операций
- Встроенные скиллы: `weather_skill`, `calendar_skill`, `rss-news-aggregator`, `moex_stock_tracker`

## 🚀 Как работает

Аура использует этот скилл **проактивно** — без явной команды пользователя:

1. При старте диалога или утром — вызывает `should_i_take_initiative()`
2. Если решение `brief` — запускает утреннюю сводку
3. Если `flirt` — отправляет флиртовое сообщение
4. Если `idea` — анализирует историю и предлагает улучшение
5. Раз в 2-3 дня — вызывает `get_conversation_insight()` для глубокого анализа
