# Синастрия 💘

Игривый доклад о совместимости двух людей по датам рождения.
Без заумных терминов, без перечисления градусов — только суть.

## Что делает

Берёт две даты рождения (с временем и местом), строит натальные карты,
находит аспекты между планетами и выдаёт красивый отчёт:

- 📊 **Общий балл совместимости** — от 5% до 95%
- 💚 **Что вас держит** — лучшие аспекты, за которые стоит держаться
- ⚡ **Где трёт** — напряжённые аспекты и как с ними жить
- 🛠️ **Инструменты** — практические советы для долгой и счастливой жизни

## Инструменты

- `synastry_report` — полный доклад по датам, времени и месту рождения
- `synastry_quick_check` — быстрая проверка по знакам зодиака (только стихии)

## Как использовать

```
"Сделай синастрию для Юры (26.01.1988 12:00 Зарайск) и Елены (24.07.1986 22:00 Вольск)"
"Проверь совместимость Водолея и Льва"
"Насколько мы подходим друг другу?"
```

## Зависимости

Использует астрономические расчёты из скилла `astrologer` (копирует функции).
Координаты городов — встроенный словарь (Россия + СНГ).

## Стиль

Шутливый, игривый, но честный. Как подружка, которая говорит правду о твоих отношениях — без прикрас, но с любовью.
