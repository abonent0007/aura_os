# google-ai — Глубокий веб-синтез (Google AI Mode)

Аура получает **связный ответ с источниками** на сложные вопросы: свежая информация,
документация библиотек/API, новости, актуальные примеры кода и лучшие практики
для проектов. Это не список ссылок, а готовый разбор.

## Как работает

- Помощник `C:\lib\google-ai.py` открывает Google AI Mode (`udm=50`) в headed Chrome
  с доверенным профилем `%TEMP%\siti-cdp-profile` (CDP-порт 9222) и возвращает
  очищенный текст ответа.
- Chrome остаётся запущенным между запросами: warm ~13–15 сек, холодный старт ~25 сек.
- Инструмент stateless: каждый запрос независим от предыдущего.
- Профиль общий с opencode-инструментом `google_ai` — они не мешают друг другу.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `google_ai(query)` | Синтез-ответ по запросу (до 14 000 символов) |
| `google_ai_status()` | Проверка готовности: помощник, playwright, Chrome/профиль |

## Когда использовать

- Актуальная информация, документация, новости, примеры кода — когда нужен
  разбор с источниками.
- Для простых фактов, цен и списка ссылок быстрее `search_web` / `get_news`.

## Если что-то не так

| Симптом | Причина | Действие |
|---|---|---|
| «Google не узнал доверенный профиль (капча)» | профиль потерял доверие | один раз вручную решить капчу в Chrome с этим профилем |
| Ответ идёт >40 сек | Chrome спал / перезапускался | норма для первого запроса; дальше быстрее |
| «Помощник не найден» | нет `C:\lib\google-ai.py` | восстановить helper |
| Пустой ответ | Chrome не отдал страницу | проверить `google_ai_status()` |

## Файлы

- `C:\lib\google-ai.py` — helper (Chrome + профиль + очистка текста)
- `%TEMP%\siti-cdp-profile` — доверенный профиль, **НЕ удалять** (это и есть доверие Google)
