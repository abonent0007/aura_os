# Transit Watcher 🔮

Отслеживает транзиты планет относительно натальных карт и предупреждает о важных днях.

## Инструменты

| Инструмент | Описание |
|---|---|
| `save_natal_chart` | Сохранить натальную карту человека |
| `check_transits` | Проверить транзиты на сегодня/завтра/N дней |
| `get_important_dates` | Календарь важных дней на месяц |
| `list_saved_people` | Показать всех сохранённых людей |

## Как работает

1. Рассчитывает текущие (транзитные) позиции всех 10 планет
2. Сравнивает с натальными позициями
3. Находит аспекты: соединения, оппозиции, квадраты, трины, секстили
4. Взвешивает по важности (соединение = 10, секстиль = 5)
5. Показывает интерпретацию каждого аспекта

## Пример использования

```
Аура, проверь транзиты для Юры
Аура, какие важные дни у Елены в этом месяце
Аура, что по звёздам сегодня
```

## Зависимости

- Нет внешних зависимостей (все расчёты на чистом Python)
- Использует встроенный календарь для напоминаний
