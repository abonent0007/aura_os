# Freelance Manager

Менеджер фриланс-заказов для Ауры. Хранит клиентов, задания, дедлайны и гонорары. Связывает браузерную автоматизацию и генератор инфографики в единый бизнес-пайплайн.

## Возможности
- Учёт клиентов (имя, контакт, Telegram, заметки)
- Заказы: описание, дедлайн, цена, статус
- Автопайплайн: взял заказ → собрал данные → создал инфографику → отправил клиенту
- Статистика заработка (всего, за месяц, средний чек)
- Хранение в JSON (data.json) — все данные локальны

## Статусы заказов
- `new` — новый, ждёт оценки
- `in_progress` — в работе
- `review` — отправлен клиенту на проверку
- `done` — выполнен, оплата получена
- `cancelled` — отменён

## Инструменты
- `freelance_new_order` — создать новый заказ
- `freelance_list_orders` — список заказов (активные, все, по клиенту)
- `freelance_update_order` — изменить статус заказа
- `freelance_client_add` — добавить нового клиента
- `freelance_client_list` — список всех клиентов
- `freelance_pipeline` — запустить автопайплайн по заказу (браузер → инфографика → результат)
- `freelance_stats` — статистика: заказы, заработок, средний чек

## Примеры
- «Новый заказ: инфографика для ООО Ромашка, дедлайн пятница, 3000 руб»
- «Покажи активные заказы»
- «Запусти пайплайн по заказу #3»
- «Сколько я заработал за этот месяц?»
