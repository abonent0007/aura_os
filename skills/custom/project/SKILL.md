# Project Workshop — Программный цех 🧰

Мастерская самостоятельного софта: здесь живут программы, которые не являются скиллами Ауры.
Этот скилл — их дверная ручка: показать проекты, прочитать файл, узнать, что сказал супервизор.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `workshop_list()` | Список проектов цеха и число файлов в каждом |
| `workshop_read(project, filename)` | Прочитать файл проекта (пути вне цеха отклоняются) |
| `supervisor_report(project)` | Последний отчёт супервизора: код возврата, время жизни, откаты |
| `supervisor_check(project, mode)` | Безопасный запуск: только `sniff` (разведка) и `status` |

## Проекты

- `auras-supervisor` — запуск Ауры, авто-откат скиллов из снапшота, отчёты в `logs/`

## Примечания
- `sniff` ничего не запускает: только показывает, какую команду супервизор найдёт.
- Полный запуск (`run`) — только вручную из терминала: он поднимает ядро и убил бы текущую сессию.
- Скилл не пишет внутрь проектов — только читает. Правки — через `edit_skill_file`.
