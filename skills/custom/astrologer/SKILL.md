# Астролог

Натальная карта, ежедневные гороскопы, фазы Луны и астрологические расчёты.
Без внешних зависимостей — все вычисления на чистом Python.

## Возможности
- Построение натальной карты по дате, времени и месту рождения
- Ежедневный гороскоп по знаку зодиака или дате рождения
- Определение знака зодиака и стихии
- Расчёт фазы Луны и лунного дня
- Сохранение данных для персонализированных прогнозов

## Инструменты
- `natal_chart` — полная натальная карта с Солнцем, Луной, ASC и планетами
- `daily_horoscope` — гороскоп на сегодня (знак или дата рождения)
- `zodiac_sign` — знак зодиака по дню и месяцу
- `save_birth_info` — сохранить данные для персонализации
- `moon_phase_info` — фаза Луны, лунный день, влияние

## Зависимости
- Нет (только стандартная библиотека Python)
- Опционально: `pip install swisseph` для профессиональной точности

## Примеры использования
- "Построй натальную карту для Юры, 26 января 1988, 12:00, Москва"
- "Гороскоп на сегодня для Водолея"
- "Какой знак зодиака 26 января?"
- "Какая сейчас фаза Луны?"
- "Сохрани мои данные для гороскопа"

## Примечания
- Точность базовых расчётов: Солнце ~1°, Луна ~5°, планеты ~10-30°
- Для профессиональной астрологии установите swisseph
- Координаты встроены для крупных городов России и СНГ
