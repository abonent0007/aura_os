# Infographic Generator

Генератор инфографики и визуализаций. Создаёт красивые карточки, диаграммы и графики на базе Pillow и matplotlib. Инструмент для автоматического создания контента под заказ.

## Возможности
- 4 типа визуализаций: карточка, барчарт, лайнчарт, пайчарт
- Настраиваемые цвета, заголовки, подписи
- Экспорт в PNG (300 DPI для печати) и PDF
- Шаблоны: «карточка товара», «статистика», «сравнение», «тренд»
- Все изображения сохраняются в `skills/infographic-generator/output/`

## Инструменты
- `ig_create_card` — создать информационную карточку (заголовок + факты + футер)
- `ig_create_barchart` — столбчатая диаграмма (сравнение категорий)
- `ig_create_linechart` — линейный график (тренды, динамика)
- `ig_create_piechart` — круговая диаграмма (доли, проценты)
- `ig_list_templates` — список доступных шаблонов и цветовых схем
- `ig_status` — статистика генератора

## Требования
- **Pillow**: `pip install pillow`
- **matplotlib**: `pip install matplotlib`
- Шрифты: используется DejaVu Sans (встроен в matplotlib) для кириллицы

## Цветовые схемы
- `business` — сине-серые тона (презентации, отчёты)
- `vivid` — яркие цвета (соцсети, маркетинг)
- `dark` — тёмная тема (технические обзоры)
- `pastel` — пастельные тона (лайфстайл, блоги)
