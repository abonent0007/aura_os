# freelance-hunter 🎯

Охотник за фриланс-заказами для Ауры. Ищет лёгкие задачи по кодингу
(скрипты, парсеры, боты, автоматизация), оценивает их и складывает в базу —
Аура предлагает лучшие варианты своему человеку.

## Как работает

```
Источники: fl.ru + hh.ru (python/удалёнка) + Habr Career + freelancer.com
      ↓
Фильтр по ключевым словам (accept/reject) + скоринг
(дубли отсеиваются до оценки — токены не тратятся)
      ↓
LLM-оценка (DeepSeek): цена, срок, черновик отклика — параллельно
      ↓
SQLite (orders.db) — дедупликация по (source, external_id)
      ↓
Аура читает базу и рассказывает о лучших заказах
```

## Источники

- **fl.ru** — фриланс-заказы
- **hh.ru** — вакансии Python (вся Россия) + удалёнка
- **Habr Career** — IT-вакансии (python, удалёнка)
- **freelancer.com** — англ. биржа (режут англ. ключевые слова)

Проверка источников (без трат токенов):

```bash
python extra_sources.py --config config.yaml --probe
```

Не работают с текущей сети и отключены: freelance.ru, freelancejob,
weblancer, freelancehunt, habr-freelance, weworkremotely, remoteok, geekjob,
kwork (JS-рендер), youdo (блокировка). Причины — в `config.yaml`.

Хочешь добавить свой — впиши RSS-ленту в `sources` в `config.yaml`
(можно задать свой `min_score`; для сайтов без RSS — `kind: html` + `pattern`).

## Быстрый старт

```bash
pip install -r requirements.txt
python extra_sources.py --config config.yaml
```

Один проход: соберёт, отфильтрует, оценит (до `estimate_limit` за раз),
сохранит. Выведет JSON-статистику с разбивкой по источникам.

## Что где

- `orders.db` — все найденные заказы (статусы: `new`, `sent`, `taken`, `rejected`)
- `config.yaml` — ленты, ключевые слова, пороги, ключи (глобальные из Ауры)
- `run_loop.bat` — цикл каждые 30 минут (для ручного запуска)

## Ключи

Использует глобальный `DEEPSEEK_API_KEY` из `.env` ядра AURA OS —
тот же, что и сама Аура. Ничего дополнительно прописывать не нужно.

## Интеграция с Аурой

Аура управляет программой через свой скилл `freelance-hunter`:
- `hunter_scan` — запустить поиск
- `hunter_orders` — показать найденное
- `hunter_mark` — пометить заказ (взял / отклонил)

Telegram-уведомления выключены (без VPN недоступны) — Аура сама расскажет
о свежих заказах в чате или окне аватара.
