# 🖨️ Auto Money Printer

Автономная программа пассивного заработка через интернет на территории РФ.  
**Легально. Без вложений. Только бесплатные API. 24/7.**

## 💡 Идея

Система объединяет 4 легальные ниши в один автономный конвейер:

| Ниша | Инструмент | Потенциал (мес) |
|------|-----------|-----------------|
| 🤖 Telegram-бот + CPA | ePN.bz / Admitad | 500–5000 ₽ |
| 📢 Telegram-канал с авто-постингом | RSS + партнёрские ссылки | 300–3000 ₽ |
| 🔄 Кэшбэк-рефералы | LetyShops / Megabonus | 200–2000 ₽ |
| 📹 YouTube Shorts (долгосрок) | MoneyPrinterTurbo + YT API | 0–∞ ₽ |

## 🚀 Быстрый старт

```bash
# 1. Клонируй / скачай проект
cd auto-money-printer

# 2. Установи зависимости
pip install -r requirements.txt

# 3. Настрой конфиг
cp .env.example .env
# Заполни .env своими ключами (см. инструкцию ниже)

# 4. Проверь конфигурацию
python main.py --check-config

# 5. Запусти систему
python main.py
```

## 🔑 Нужные API-ключи (все бесплатные)

| Сервис | Где получить | Бесплатный лимит |
|--------|-------------|------------------|

## ⚖️ Легальность

- Все CPA-ссылки маркируются #реклама
- Бот не спамит: рассылка только подписавшимся, не чаще раза в сутки
- При доходе > 50 000 ₽/год — регистрация самозанятости (налог 4–6%)
- Контент генерируется AI или берётся из RSS (допустимо по ст. 1274 ГК РФ)

## ⚠️ Важно

Это НЕ волшебная кнопка. На старте доход минимален (50–300 ₽/день).  
Рост требует времени на раскрутку каналов и накопление аудитории.
