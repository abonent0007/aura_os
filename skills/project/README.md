# Инженерный цех

Здесь живут проектные скиллы — кодогенерация, архитектура, CI/CD, парсеры, код-ревью и все инструменты для реальной разработки.

В отличие от `builtin/` (личность Ауры) и `custom/` (интеграции с внешними API), эта папка — твой личный верстак для инженерных задач.

## Структура скилла (такая же как везде)

```
project_skill/
├── manifest.json
├── SKILL.md
└── skill.py
```

## Что создавать здесь

- Парсеры и генераторы кода
- Инструменты для работы с Git
- Шаблонизаторы проектов
- Скрипты код-ревью
- CI/CD хелперы
- Всё что связано с написанием и поддержкой кода

## Как использовать

1. Создай папку скилла с тремя файлами
2. Перезапусти AURA OS
3. Скилл подхватится автоматически
4. Вызови инструменты через Ауру: «запусти код-ревью», «сгенерируй шаблон проекта»

Аура видит эту папку наравне с `builtin/` и `custom/`.
