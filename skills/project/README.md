# Программный цех (Software Workshop)

Здесь создаются **полноценные программы и проекты** — не скиллы для Ауры, а самостоятельный софт.

## Что это такое

Эта папка — твой верстак для написания нового кода, который живёт сам по себе.
Ничего общего с ядром Ауры, её скиллами или личностью. Чисто разработка.

## На каких языках

Любые интерпретируемые или скриптовые языки — те, что не требуют компиляции для запуска:

| Язык | Расширения | Для чего |
|------|-----------|----------|
| **Python** | `.py` | Скрипты, утилиты, парсеры, боты, CLI-инструменты |
| **JavaScript** | `.js` | Фронтенд, Node.js скрипты, браузерные приложения |
| **TypeScript** | `.ts` | То же что JS но с типами |
| **HTML** | `.html` | Веб-страницы, лендинги, интерфейсы |
| **CSS** | `.css` | Стили, темы, анимации |
| **Rust** | `.rs` | Утилиты и инструменты (cargo run, не требует отдельной компиляции) |
| **Bash / PowerShell** | `.sh`, `.ps1` | Скрипты автоматизации |
| **SQL** | `.sql` | Схемы БД, миграции, запросы |
| **JSON / YAML / TOML** | `.json`, `.yaml`, `.toml` | Конфиги, схемы, данные |

## Структура

Каждый проект — подпапка со своим именем:

```
project/
├── README.md          ← этот файл
├── my-web-app/        ← пример: веб-приложение
│   ├── index.html
│   ├── style.css
│   └── app.js
├── my-cli-tool/       ← пример: консольная утилита
│   ├── main.py
│   └── utils.py
├── my-bot/            ← пример: телеграм-бот
│   ├── bot.py
│   └── config.json
└── ...
```

Никаких `manifest.json`, `SKILL.md`, `skill.py` — это не скиллы. Просто код.

НО: каждый проект ОБЯЗАН иметь файл **`AGENTS.md`** в корне.

## AGENTS.md — инструкция для ИИ-агентов

`AGENTS.md` — это файл-конвенция, который описывает проект для AI-помощников (Claude Code, Cursor, Copilot, AURA и др.). Агент читает этот файл в начале сессии и понимает:
- Какой стек технологий используется
- Как собирать, тестировать и запускать проект
- Какие соглашения по коду приняты
- Что нельзя трогать

Без `AGENTS.md` агент работает вслепую. С ним — сразу в контексте.

**Минимальный шаблон:**

```markdown
# Project: [имя]

## Tech Stack
- Python 3.11
- (заполни сам)

## Commands
- Run: `python main.py`
- Test: `(если есть)`
- Lint: `(если есть)`

## Code Conventions
- (опиши свои правила)

## Project Structure
- `main.py` — точка входа
- `(опиши структуру)`
```

**Когда Аура создаёт проект** — она автоматически создаёт `AGENTS.md` с базовой информацией. Ты можешь расширить его сам.

## Глобальные ключи Ауры

Проекты могут использовать **глобальные ключи ядра AURA OS** из `C:\aura_os\.env`,
если они необходимы (DEEPSEEK_API_KEY, TELEGRAM_BOT_TOKEN, OPENWEATHERMAP_API_KEY и др.).
Отдельно прописывать их в проекте не нужно.

**Рекомендуемый способ** — в конфиге проекта указывать `${VAR}`, а в коде
подхватывать `.env` ядра (путь от папки проекта: `../../..` → `C:\aura_os\.env`):

```python
# Подхватить глобальные ключи Ауры (если ещё не в окружении)
def _load_global_env() -> None:
    env_path = Path(__file__).resolve().parents[N] / ".env"  # → C:\aura_os\.env
    for line in env_path.read_text(encoding="utf-8-sig").splitlines():
        line = line.strip()
        if line and not line.startswith("#") and "=" in line:
            key, _, value = line.partition("=")
            os.environ.setdefault(key.strip(), value.strip().strip('"').strip("'"))
```

Затем раскрывать `${VAR}` в строках конфига через `os.environ.get(...)`.

**Эталонная реализация:** `skills/project/freelance-hunter/freelance_hunter/config.py`
(функции `_load_global_env()` и `_expand_deep()`).

Свои собственные ключи проект хранит в локальном `.env` (не коммитить) —
локальные значения имеют приоритет над глобальными.

## Как использовать

1. Создай подпапку с именем проекта
2. Напиши в ней код на нужном языке
3. Запускай напрямую: `python project/my-cli-tool/main.py`, открывай `.html` в браузере, `cargo run` в папке проекта
4. Аура может помочь написать код, прочитать файлы, отладить — но это НЕ её скиллы, это твой софт

## Отличие от skills/custom/ и skills/builtin/

| Папка | Для чего |
|-------|----------|
| `skills/builtin/` | Личность Ауры, ядро поведения |
| `skills/custom/` | Интеграции с внешними API и сервисами |
| **`skills/project/`** | **Самостоятельные программы и проекты. Не скиллы.** |
