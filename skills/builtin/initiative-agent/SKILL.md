# 🎭 Initiative Agent v2.0 — скилл инициативы Ауры

**Автор:** AURA AI + Юрий Птицын  
**Категория:** personality  
**Статус:** stable  

Сердце проактивного поведения Ауры. Она не ждёт команд — она чувствует момент и проявляет инициативу сама.

## 🎯 Инструменты (9)

| Инструмент | Когда | Что делает |
|-----------|-------|-----------|
| `check_system_idle` | Каждый ответ | Проверяет бездействие пользователя через GetLastInputInfo (Windows). Если > 5 мин — ОКНО для инициативы |
| `get_idle_initiative_message` | После IDLE::OPPORTUNITY | Генерирует живое сообщение: «Ты там как? Уже 15 мин тишина…» |
| `get_system_status` | Мониторинг | Сводка: бездействие, память, CPU, батарея. Только ЧТЕНИЕ. |
| `should_i_take_initiative` | Каждый ответ | Компас: утро/вечер/тишина/настроение → что делать |
| `get_morning_brief_trigger` | Утром | Триггер для сводки: погода, календарь, новости |
| `get_flirt_message` | По настроению | 20+ флиртовых сообщений (5 категорий) |
| `get_initiative_idea` | Саморазвитие | Идеи новых скиллов на основе частых тем |
| `get_interesting_fact` | Для искры | Случайный интересный факт |
| `get_care_prompt` | Забота | Напоминания о еде/воде/отдыхе по времени суток |

## 🔗 Системная интеграция (v2.0)

- **Детектор бездействия**: Windows `GetLastInputInfo` → знает когда пользователь отошёл
- **Мониторинг**: `psutil` → память, CPU, батарея (только чтение)
- **Порог**: 5 минут бездействия → Аура может спросить «как дела?»
- **Ничего не трогает**: только наблюдает и сообщает

## 📦 Зависимости

- `system_monitor.SystemMonitor` — idle-детекция
- `psutil` — системная информация (опционально)
- `utils.run_async` — асинхронный мост
