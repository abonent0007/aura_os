# RSS News Aggregator

Собирает новости из RSS-лент: Lenta.ru, Google News, RIA Новости, Rambler.

## Возможности

- Сводка новостей по категориям: Москва, Россия, Мир, Бизнес, Спорт
- Поиск новостей по конкретной теме через Google News + fallback на Lenta.ru
- Красивая структурированная выдача с датами и источниками

## Источники

- **Lenta.ru** — основной источник, универсальная лента
- **Google News RSS** — поиск по темам
- **RIA Новости** — архивная лента
- **Rambler** — бизнес-новости

## Использование

Спроси Ауру: «что нового?», «новости Москвы», «что там в спорте», «поищи новости про криптовалюту».

## Инструменты

### get_news(category)
Сводка свежих новостей. category: `Москва`, `Россия`, `Мир`, `Бизнес`, `Спорт`, или `all` (по умолчанию — все).

### search_news_by_topic(topic)
Поиск новостей по ключевым словам. Сначала идёт в Google News, если не отвечает — фильтрует Lenta.ru.

### list_news_sources()
Показать все доступные источники новостей с URL.
