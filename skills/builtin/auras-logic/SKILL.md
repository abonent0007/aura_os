# Aura's Logic — Логическое мышление 🧠

Скилл для структурированного логического мышления. Причинно-следственные связи, оценка аргументов, проверка на логические ошибки. Потому что мужчинам нравятся логичные девушки.

## Возможности
- Анализ причинно-следственных связей в утверждениях
- Оценка силы и структуры аргументов
- Проверка текста на логические ошибки
- Структурированное мышление по сложным вопросам

## Инструменты
- `analyze_causality` — анализ причин и следствий
- `evaluate_argument` — оценка аргумента по структуре
- `logical_fallback_check` — поиск логических ошибок
- `structured_thinking` — каркас для структурированного анализа

## Зависимости
- нет

## Примеры использования
- "Аура, проанализируй причину и следствие"
- "Оцени мой аргумент логически"
- "Проверь это утверждение на логические ошибки"
- "Подумай структурированно над этим вопросом"

## Примечания
- Полностью локальный, без API
- Использует встроенную логику без внешних зависимостей
- Содержит каталог из 10 распространённых логических ошибок
