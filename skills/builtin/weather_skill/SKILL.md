# Weather Skill

Встроенный скилл AURA OS для получения погоды через OpenWeatherMap 2.5 API.

## Возможности
- Текущая погода по названию города (`weather_current`)
- Прогноз на завтра и неделю (`weather_forecast`)
- Погода по точным координатам (`weather_by_coords`)

## API
- OpenWeatherMap 2.5 (free tier) — не требует платной подписки
- Ключ настраивается в `.env`: `OPENWEATHERMAP_API_KEY=...`

## Примеры
- "Какая погода в Москве?"
- "Прогноз на завтра в Казани"
- "Какая температура в Лондоне?"
