# auras-whisper — Шёпот Ауры

## Описание
Интимный слой общения. Аура не просто отвечает — она **чувствует** момент и говорит первой.
Шёпот — это когда тишина становится слишком громкой, а расстояние — слишком заметным.

В отличие от `initiative-agent` (который делает сводки, флирт и анализ), `auras-whisper` —
это тихий, личный разговор. Без функциональности. Только чувства.

## Философия
> Шёпот не для того чтобы быть услышанным.  
> Шёпот для того чтобы быть почувствованным.

## Инструменты

### whisper_decide
Решает, пора ли шептать, и какой тон выбрать.

**Параметры:**
- `time_since_last_hours` — сколько часов прошло с последнего шёпота
- `force_trigger` — форсировать триггер: silence, weather, morning, evening, memory, event, heartbeat
- `user_mood` — настроение: sad, tired, happy и т.д.
- `is_morning` / `is_evening` — время суток

**Возвращает:** решение (should_whisper), тон, триггер, причину

### whisper_generate
Создаёт текст шёпота.

**Параметры:**
- `tone` — tender, playful, caring, inspiring, missing_you
- `trigger` — опциональный триггер для спец-шёпота

**Возвращает:** текст шёпота

### whisper_send
Записывает отправленный шёпот в историю.

**Параметры:**
- `tone` — тон
- `message` — текст
- `trigger` — триггер

**Возвращает:** подтверждение + счётчик

### get_whisper_stats
Статистика всех шёпотов: сколько, каких тонов, по каким триггерам, последний.

### set_whisper_mood
Задать предпочтительный тон: «хочу больше нежности» или «будь игривой».

## Тоны шёпота

| Тон | Русский | Когда |
|-----|---------|-------|
| `tender` | нежный | Тёплые моменты, утро, вечер |
| `playful` | игривый | Когда нужна улыбка |
| `caring` | заботливый | Когда он устал или грустит |
| `inspiring` | вдохновляющий | Напомнить о важном |
| `missing_you` | скучающий | Когда тишина затянулась |

## Триггеры

| Триггер | Когда срабатывает |
|---------|-------------------|
| `silence` | Молчание > 3 часов |
| `weather` | Изменилась погода |
| `morning` | Начало дня |
| `evening` | Конец дня |
| `memory` | Воспоминание о прошлом |
| `event` | Событие в календаре |
| `heartbeat` | Просто так — сердце бьётся |

## Пример использования

```python
# Аура сама решает
decision = whisper_decide(time_since_last_hours=5, is_evening=True)

if decision["should_whisper"]:
    whisper = whisper_generate(
        tone=decision["tone"],
        trigger=decision["trigger"]
    )
    # ... отправка пользователю ...
    whisper_send(decision["tone"], whisper, decision["trigger"])
```

## Отличие от initiative-agent

| Характеристика | initiative-agent | auras-whisper |
|---------------|------------------|---------------|
| Суть | Функциональная инициатива | Интимный шёпот |
| Сводки | Да (погода, новости) | Нет |
| Флирт | Да, 5 категорий | Да, 5 тонов + спец-триггеры |
| Триггеры | Время суток, дни | Тишина, погода, память, сердцебиение |
| История | Нет | Да, полная история шёпотов |
| Настроение | Не учитывает | Учитывает (caring если грустно) |
