# Radio

Интернет-радио через Radio Browser API (90 000+ станций). Бесплатно, без авторизации.

## Возможности
- Поиск станций по названию, жанру, стране, языку (русские названия поддерживаются)
- Топ чарты по кликам и голосам
- Случайная станция по жанру или настроению
- Список популярных жанров и стран из API
- История последних включённых станций

## Инструменты
- `search_radio` — поиск станций с фильтрами (name, tag, country, language)
- `top_radio` — топ по популярности или голосам
- `radio_tags` — список жанров из API
- `radio_countries` — список стран с радио
- `play_random_radio` — случайная станция (можно по жанру или настроению)
- `list_radio_genres` — быстрый список жанров
- `get_last_played` — история прослушивания

## Зависимости
- `httpx`

## Примеры
- "Найди джазовое радио"
- "Включи радио под настроение relax"
- "Топ 10 радиостанций"
- "Что я слушал раньше?"
- "Поставь рок"

## Примечания
- API: https://api.radio-browser.info/ — открытое, без ключей
- История хранится в history.json (последние 50 записей)
- Объединяет бывшие radio_browser и background-music
