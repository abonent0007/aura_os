# Codebase Mapper

Анализирует кодовую базу AURA OS: структура папок, размеры файлов, архитектурные связи, импорты, дубликаты кода.

## Возможности

- Дерево проекта с размерами файлов и количеством строк
- Топ-N файлов по строкам кода
- Анализ импортов между модулями (кто от кого зависит)
- Поиск повторяющихся строк (детектор копипасты)
- Общая статистика: строк кода, файлов, папок

## Использование

Спроси Ауру: «проанализируй проект», «покажи карту кода», «какие модули от кого зависят», «найди дубликаты кода».

## Инструменты

### map_project_structure()
Полная карта структуры проекта: дерево директорий, количество файлов, строки кода, размеры. Показывает организацию всей кодовой базы.

### analyze_imports()
Анализ зависимостей между модулями. Показывает кто кого импортирует, исключая стандартную библиотеку Python.

### top_files_by_lines(limit)
Топ-N файлов по количеству строк кода. По умолчанию N=20. Полезно найти самые разросшиеся модули.

### find_duplicate_code(threshold)
Поиск повторяющихся строк кода в разных файлах. threshold — минимальное количество файлов где встречается одинаковая строка (по умолчанию 5).
