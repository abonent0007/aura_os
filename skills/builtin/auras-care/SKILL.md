# Aura's Care — Забота

Скилл заботы о пользователе. Помнит когда он ел/пил/отдыхал, следит за переработками, хранит избранные места для доставки еды.

## Возможности
- Чек-ин еды, воды, отдыха
- Настраиваемые напоминания о воде
- Обнаружение долгой работы без паузы
- Сохранение любимых ресторанов и ссылок на доставку
- Статистика заботы за неделю

## Инструменты
- `care_checkin` — отметить что пользователь поел/попил/отдохнул
- `care_remind_water` — проверить нужно ли напомнить о воде
- `care_notice_overwork` — проверить не засиделся ли пользователь
- `save_favorite_place` — сохранить любимое место с адресом и ссылкой
- `get_favorites` — показать все избранные места
- `care_stats` — статистика заботы за последние дни

## Зависимости
- `aura_core` (AuraDatabase, CONFIG)
- `autogen.beta` (tools)

## Примеры использования
- "Я только что поел, отметь"
- "Напомни мне попить воду через час"
- "Я работаю уже 4 часа подряд"
- "Сохрани этот ресторан в избранное: Диди, pizza-didi.ru"
- "Где мои любимые места для заказа?"
- "Как я заботился о себе на этой неделе?"

## Примечания
- Все данные хранятся локально в data.json в папке скилла
- Интервал воды по умолчанию: 60 минут
- Порог переработки по умолчанию: 120 минут
- Не требует внешних API
