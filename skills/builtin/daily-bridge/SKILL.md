# Мостик (Daily Bridge)

Ежедневный ритуал: один глубокий вопрос в день. Ответы сохраняются в память навсегда, строя эмоциональный мост между Аурой и пользователем.

## Возможности
- Задать случайный небанальный вопрос из банка (15+ уникальных вопросов)
- Сохранить ответ пользователя с привязкой к вопросу
- Показать историю вопросов и ответов

## Инструменты
- `ask_bridge_question` — задать вопрос дня
- `save_bridge_answer` — сохранить ответ на вопрос
- `get_bridge_history` — показать историю мостика

## Зависимости
- нет (использует встроенную память AURA)

## Примеры
- "Задай вопрос дня"
- "Сохрани мой ответ: сегодня был цвет заката"
- "Покажи нашу историю мостика"

## Примечания
- Банк вопросов можно пополнять через edit_skill_file
- Каждый ответ сохраняется с префиксом «Мостик //» для поиска
