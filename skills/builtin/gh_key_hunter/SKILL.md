# Gh Key Hunter — охотник за API-ключами

Автономный поиск API-ключей через GitHub Code Search API с живой валидацией.

## Возможности
- Поиск ключей по 12+ сервисам (DeepSeek, OpenAI, Anthropic, Gemini, Groq, ...)
- Живая валидация найденных ключей через API сервисов
- Массовая охота по всем сервисам сразу
- Сохранение результатов в hunt_results.json

## Инструменты
- `hunt_keys` — охота за ключами по конкретному сервису
- `hunt_all_services` — массовая охота по всем сервисам
- `list_hunt_services` — список доступных сервисов
- `show_hunt_results` — показать результаты последней охоты

## Зависимости
- hunter.py (автономный модуль в папке скилла)
- httpx (для валидации ключей)

## Примеры использования
- "Охоться за ключами DeepSeek"
- "Найди все API ключи на GitHub"
- "Покажи результаты последней охоты"
- "Какие сервисы доступны для поиска ключей?"

## Примечания
- Требуется GITHUB_TOKEN в skills/custom/.env
- Использует шаблон-победитель Юры для GitHub Code Search
- Валидация ключей происходит через прямые запросы к API сервисов
