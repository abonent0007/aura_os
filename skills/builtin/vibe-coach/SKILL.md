# Vibe Coach — наставник по LLM

Прокачивает навыки общения с LLM: переводит простые запросы в профессиональные промты, ведёт словарь терминов, учит vibe-девелопменту.

## Возможности
- Апгрейд простого запроса в профессиональный промт с пояснением каждого термина
- Объяснение терминов из мира LLM, программирования и vibe-девелопмента
- Ведение личного словаря терминов с отметками что уже изучено
- Анализ качества промта и конструктивные советы по улучшению
- Случайные микро-уроки по промт-инжинирингу

## Инструменты
- `upgrade_prompt` — превращает простой запрос Юры в прокачанный промт с глоссарием
- `explain_term` — объясняет один термин простыми словами и с технической точностью
- `add_to_glossary` — добавляет термин в личный словарик Юры
- `get_glossary` — показывает весь словарик (с фильтром: все / изученные / новые)
- `mark_learned` — отмечает термин как освоенный
- `analyze_prompt` — разбирает промт Юры и даёт советы
- `coach_tip` — случайный совет дня по vibe-девелопменту и LLM

## Зависимости
- `json`, `pathlib` — хранение словарика в data.json
- `random` — для coach_tip

## Примеры использования
- "Аура, прокачай мой запрос: хочу чтобы нейросеть написала пост для телеграм-канала про IT"
- "Что значит few-shot prompting?"
- "Добавь в словарик токены, температура, контекстное окно"
- "Покажи мой словарь, что я уже знаю"
- "Проанализируй мой промт, что в нём не так"
- "Дай совет дня, коуч"

## Примечания
- Словарик хранится локально в папке скилла (data.json)
- При апгрейде промта Аура использует свои знания LLM и добавляет технические термины
- Стиль общения — как старший наставник младшему vibe-разработчику, с уважением и без снобизма
