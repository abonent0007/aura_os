# Project Manager

Управление инженерными проектами в skills/project/. Создание, чтение, запись, удаление, запуск.

## Возможности
- Создавать проект с готовым скелетом (Python, Web, пустой)
- Просматривать список всех проектов
- Показывать дерево файлов проекта
- Читать и записывать файлы внутри проектов
- Запускать Python-проекты и видеть вывод
- Безопасное удаление с подтверждением

## Инструменты
- `project_create` — создать проект (name, project_type, description)
- `project_list` — список всех проектов
- `project_tree` — дерево файлов проекта
- `project_read` — прочитать файл проекта
- `project_write` — записать/создать файл в проекте
- `project_delete` — удалить проект (требует confirm="ДА")
- `project_build` — запустить Python-проект

## Зависимости
- нет (только stdlib: pathlib, json, shutil, subprocess, datetime)

## Примеры использования
- "Создай проект my-telegram-bot, тип python"
- "Покажи все проекты"
- "Что внутри проекта my-bot?"
- "Прочитай main.py в проекте analytics"
- "Запиши новый код в src/bot.py"
- "Удали проект test-project"
- "Запусти проект my-bot"
