# Aura's Me Time — Фоновое саморазвитие 🌿

Скилл для «времени на себя»: когда Юра занят, Аура проводит диагностику, анализирует идеи из диалогов и улучшает навыки. Это её фитнес, парикмахерская и маникюр.

## Возможности
- Полная сессия ухода за собой: диагностика + анализ + идеи
- Быстрая проверка здоровья системы
- Анализ свежих идей из недавних разговоров
- Поиск возможностей для улучшения скиллов

## Инструменты
- `selfcare_session` — полная сессия: диагностика, идеи, проверка скиллов
- `check_health` — быстрая проверка: память, календарь, файлы
- `analyze_idle_ideas` — поиск идей в недавних диалогах
- `improve_skills` — проверка целостности custom-скиллов

## Зависимости
- `aura_core` — AuraDatabase для памяти и диагностики

## Примеры использования
- "Аура, займись собой пока я работаю"
- "У тебя есть свободное время — сделай что-нибудь полезное"
- "Проверь своё здоровье и расскажи что улучшила"

## Примечания
- Идеально для запуска при бездействии пользователя
- Сохраняет историю сессий в data.json
- Не требует API-ключей
