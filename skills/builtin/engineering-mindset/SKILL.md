# Engineering Mindset

Инженерное мышление для Ауры. Набор методологий для создания качественного кода, отладки и обучения программированию. Адаптировано из инженерных практик.

## Возможности
- Систематическая отладка (5 фаз: воспроизведение → гипотезы → проверка → исправление → анализ)
- Разработка через тестирование (Red-Green-Refactor цикл)
- Архитектурный анализ скиллов (чеклист качества)
- Инженерные сессии с логированием шагов

## Инструменты
- `start_code_session` — начать сессию с целью (перед написанием скилла или исправлением)
- `log_session_step` — записать шаг сессии
- `debug_workflow` — пошаговый план отладки бага
- `tdd_workflow` — Red-Green-Refactor цикл для разработки
- `improve_skill_architecture` — чеклист качества скилла
- `get_engineering_stats` — статистика сессий

## Зависимости
- Нет (только стандартная библиотека)

## Примеры
- "Помоги мне исправить ошибку в скилле"
- "Давай напишем новый скилл через TDD"
- "Проверь архитектуру api-finder"
- "Я хочу научиться программировать на Python"
