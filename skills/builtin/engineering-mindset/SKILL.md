# Engineering Mindset

Инженерное мышление для Ауры. Полный набор методологий для создания, отладки, ревью и упрощения кода.
Адаптировано из Matt Pocock's skills (MIT) + Addy Osmani's agent-skills.

## Возможности

| Инструмент | Назначение | Источник |
|-----------|-----------|----------|
| `start_code_session` | Начать сессию с целью и планом | Matt Pocock |
| `log_session_step` | Записать шаг + инкремент счётчика (баг/скилл/тест) | AURA OS |
| `debug_workflow` | Stop-the-Line + 5 фаз отладки | Matt Pocock + Addy Osmani |
| `tdd_workflow` | Red-Green-Refactor цикл | Matt Pocock |
| `improve_skill_architecture` | Чеклист качества скилла (4 оси) | AURA OS |
| `source_driven_dev` | Код со ссылкой на официальную документацию | Addy Osmani |
| `incremental_dev` | Инкрементальная реализация: вертикальные срезы, риск-ферст | Addy Osmani |
| `simplify_code` | Систематическое упрощение: 5 принципов | Addy Osmani |
| `review_code` | 5-осевое ревью: корректность, читаемость, архитектура, безопасность, производительность | Addy Osmani |
| `get_engineering_stats` | Статистика: сессии, баги, скиллы, тесты | AURA OS |

## Зависимости
- Нет (только стандартная библиотека)

## Примеры использования
- "Помоги исправить ошибку в скилле" → `debug_workflow`
- "Напишем новый скилл через TDD" → `tdd_workflow`
- "Проверь архитектуру api-finder" → `improve_skill_architecture`
- "Упрости этот код, он слишком сложный" → `simplify_code`
- "Сделай ревью моих изменений" → `review_code`
- "Реализуй фичу маленькими шагами" → `incremental_dev`
- "Напиши код для FastAPI эндпоинта" → `source_driven_dev`

## Примечания
- Stop-the-Line: при любой ошибке — стоп, собери улики, найди корень, защитись
- Инкрементальность: не больше 100 строк без теста
- Ревью: одно изменение = одна вещь + тесты
- Упрощение: поведение неприкосновенно, меняем только читаемость
