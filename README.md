## Changelog v4.14.0 — Непрерывность диалога, темы, сжатие, зрение

Ветка `feature/continuity`.

- **Непрерывность**: таблица `dialogue_turns` (общий `session_id=main` для Telegram и веба) + FTS по репликам. После рестарта поднимаются последние 8 реплик дословно; `search_memory` ищет и по репликам, и по дневнику.
- **Незакрытые темы**: `open_topics` (вопрос без ответа, обещание, задача). После паузы > 2 ч в контекст подставляется блок «Незакрытые темы», в лог пишется `context: open topics injected ...`.
- **Антишаблонность**: в промпт добавлены правила (не заканчивать каждый ответ вопросом, максимум один вопрос, не повторять зачины); soft-постпроцессор сводит два вопроса подряд к одному.
- **`summarize_history(keep_last=10)`**: сжатие старых реплик через compactor, статистика токенов до/после, саммари восстанавливается в контекст.
- **Зрение по фразе**: «посмотри», «что на экране», «видишь» → автоскриншот и vision (не чаще 1/60с, приватные просьбы игнорируются).
- **Ретеншн**: 500 реплик / 30 дней с автоочисткой при старте.
- Тесты: **115** (+10).
