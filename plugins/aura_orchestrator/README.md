# AURA OS — Плагин: Мультиагентный Оркестратор

## Назначение
Глубокий анализ сложных вопросов через параллельный запуск нескольких ИИ-персон. Используется как инструмент AURA (`orchestrator_run`) и отдельно через `/expert` в Telegram или `/api/chat/expert`.

## Архитектура (flattened)
```
Запрос → AURA решает какие персоны нужны
         → параллельный запуск выбранных персон
         → дедупликатор (sentence-transformers)
         → ответ
```

Убраны анти-паттерны:
- **Container 1 (роутер)** — AURA сама решает какие персоны, без лишнего LLM-вызова
- **Container 3 (обозреватель)** — дедуплицированный ответ идёт напрямую AURA или пользователю

## Персоны

| Роль | Назначение |
|------|-----------|
| `coordinator` | План и архитектура решения |
| `researcher` | Глубокий анализ, альтернативы, подводные камни |
| `developer` | Код и практическая реализация |
| `reviewer` | Ревью кода на ошибки и уязвимости |
| `planner` | Дорожная карта, риски, этапы |

## Использование

### 1. Как инструмент AURA (`orchestrator_run`)
AURA вызывает сама, когда решает что вопрос сложный и нужны разные точки зрения.

По умолчанию запускает: coordinator + researcher + developer.
Может выбрать любую комбинацию: `orchestrator_run(query="...", roles="researcher,planner")`

### 2. Telegram: команда `/expert [вопрос]`
- Без аргументов — включает режим Эксперт
- С аргументами — отправляет вопрос оркестратору, после ответа авто-возврат к AURA
- Запускает все 3 базовые персоны (coordinator + researcher + developer)

### 3. Web API: `POST /api/chat/expert`
Тело: `{"text": "вопрос"}` — запускает все 3 базовые персоны

## Установка
```bash
pip install sentence-transformers openai
```

## Ключ API
Используется `DEEPSEEK_API_KEY` из `.env` (основной ключ проекта).

## Временные файлы
Создаются в `%TEMP%/aura_orchestrator/`, удаляются после каждого ответа.
